超相対性理論 #270 リーダーシップは誰のもの？／ゲスト：黒川公晴さん（その3）

ゲストに黒川公晴氏を迎え、リーダーシップの概念を「個人への帰属」から「システムの中の現象」へと捉え直す議論の第3回。教育現場での実践、役割の分散、そして認知のスポットライトを広げることの重要性について深掘りします。

📌 教育現場での実践と「世界は変えられる」の危うさ

  • 教育現場での取り組み：東京の学童（カリキュラム監修）や福岡の小学校（4〜6年生の総合学習）で、システム思考や思考習慣をプロジェクト型・共同型で学ぶ場を提供している。
  • フィロソフィー「世界は本当は変えられる」：半径3〜5メートルでも変化は作れるという感覚を子供のうちに持ってほしいという願い。大人の無力感に対するメッセージでもある。
  • 潜在的なリスク：
    • 「変えられる」を善とすると、変えられなかった子や変えたいと思わない子が取り残される。
    • ハイパーメリットクラシー：全人格的なリーダーシップが評価対象になると、家庭の経済・文化的環境による格差が顕在化する懸念がある。

📌 ゴフマンの「フッティング」による役割の分散

リーダーシップを一人の人間に固定せず、役割の分担として捉え直す視点。アーヴィン・ゴフマンの論文「フッティング」における「話し手」の3分類をリーダーシップに応用する。

  • 具体例：トルシェ監督と通訳ダバディ氏
    • ダバディ氏：アニメーター（発話）であり、日本語の選択においてはオーサーの一部。しかしプリンシュパル（責任主体）ではない。
    • トルシェ氏：オーサーでありプリンシュパルだが、日本語でのアニメーターではない。
  • 組織への応用：経営者のスピーチにおいて、オーサーが経営企画部、プリンシュパルが経営者というように、リーダーシップは日常的に分散されている。

📌 認知のスポットライトを広げる

  • Do（行為）とBe（存在）：表立ったリーダーの「Do」だけでなく、それを支えた人、好意的に見ていた人、ただそこにいた人（Be）の相互作用によって現象が起きている。
  • 正当な謙虚さの表現：
    • アカデミー賞のスピーチ：無名のプロデューサーの名前を連呼するのは、個人の功績ではなく周囲のDoとBeへの敬意の表れ。
    • イチローの殿堂入りスピーチ：多くの関係者の名前を呼ぶことで、自分一人の力ではないことを示す。
  • 教育・組織でのハイライト：目立たないサポーターやフォロワーの関わりを言語化し、光を当てる（ハイライトする）文化の重要性。

📌 ナラティブの書き換えとライフラインチャートの功罪

  • ライフラインチャートの限界：個人のモチベーショングラフは、スポットライトの照射範囲が極めて狭く、単純化された因果関係（機械論的世界観）に基づいている。
  • 照射範囲の拡大トレーニング：
    • 自分の成功の背後に誰がいたか（朝食を作ってくれた母親まで含める）。
    • 自分のネガティブな出来事（負け）が、他者の喜びやシステム全体のポジティブな変化に繋がっている可能性を考える。
  • 「負けるリーダーシップ」の肯定：勝者だけがリーダーシップを持つのではなく、滅びゆく側や負けた側も現象の一部としてリーダーシップを担っている。
  • 現代の課題：就活などの「短時間で分かりやすい」コミュニケーションが求められる場では、こうした「まどろっこしい」相互作用のナラティブは伝わりにくい。
