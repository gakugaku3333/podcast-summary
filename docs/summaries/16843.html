超相対性理論 #266 世の中ダチ公主義すぎるのでは？（その3）

朝日新聞の神田大介氏をゲストに迎え、「ダチ公主義（身内・仲間を優先する考え方）」が社会に与える影響を深掘りする第3回。神田氏自身の「マージナル（境界人）」な生い立ちから、知識人の在り方、そして社会の停滞とダチ公主義の因果関係について議論が交わされます。

ダチ公主義 神田大介 マージナル・マン（境界人） エドワード・サイード コウモリ MSX 知識人 ゼロサムゲーム 東浩紀 ピーター・ティール

📌 神田大介氏の「マージナル」なルーツ

  • 出自は「オタク」： 子供時代はMSX（パソコン）でプログラミングをして自作ゲームを作るような、典型的なオタク気質だった。
  • ヤンキー中学校での生存戦略： 進学先が「廊下に吸い殻が落ち、トイレの便器が破壊されている」ような荒れた中学校だった。そこで生き抜くためにヤンキーともコミュニケーションを取る必要があり、結果として生徒会長を務めながら番長グループとも渡り合う「境界人」としての立ち位置が形成された。
  • 朝日新聞社内での違和感： 恵まれた環境で育った人が多い組織の中で、特定のイデオロギーに依存しない自分は常に「どこにも所属できていない感覚」を抱えている。
  • 共感の欠如と記者としての利点： 取材対象に深く共感したり寄り添ったりすることに関心がない。しかし、その「冷めた視点」が、世の中や人間を客観的に観察する上では都合が良いと感じている。

📌 知識人の在り方：亡命者・アウトサイダー・アマチュア

思想家エドワード・サイードの著書『知識人とは何か』を引用し、理想的な知識人の姿について議論されました。

  • 亡命者としての知識人： どこにも所属せず、常にアウトサイダー（コウモリ）であるべき。
  • 専門家 vs アマチュア：
    • 専門家： 特定のイデオロギーや集団の利益のために働く人。
    • アマチュア： どこの息もかかっておらず、権力に対して本当のことが言える人。
  • 二律背反の悩み： 広く浅い「コウモリ」的なスタンスは自由だが、専門家のような「洞察の深さ」や「研究の確かさ」を得にくいという葛藤がある。
属性 専門家 / 所属する人 アマチュア / コウモリ（境界人）
視点 内部利益・特定のイデオロギー 客観的・普遍的原理
強み 専門性の深さ・謎の解明 移動の自由・権力への批判
弱み 本当のことが言えなくなる 知識が薄く浅くなりがち

📌 リベラル・保守とダチ公主義のねじれ

  • 是々非々の難しさ： 東浩紀氏のように、リベラルでありながらリベラル側の矛盾を批判する（是々非々）と、身内（ダチ）から「敵か味方か」を問われ、激しく叩かれる構造がある。
  • 原理 vs 仲間： 本来リベラルは「普遍的な原理」を、保守は「身近な仲間」を大事にするはずだが、現状はどちらの陣営も「ダチ公主義」に陥り、普遍的な真理が置き去りにされている。
  • SNSによる加速： 敵対関係が可視化されやすいSNSでは、短期的な表面上のコミュニケーション（味方へのアピール）に終始しやすくなっている。

📌 社会の停滞とダチ公主義の因果関係

深井氏による「停滞がダチ公主義を生む」という逆説的な仮説が提示されました。

  • 成長期： パイが拡大している時は、外部と協力して新しい価値を生む方が得なので、人は「開かれた」状態になる。
  • 停滞期： パイが縮小すると、限られた資源を奪い合う「ゼロサムゲーム」になる。効率よく奪うために仲間同士で固まり、敵を攻撃する「ダチ公主義」が悪化する。
  • 結論： ダチ公主義は停滞の「原因」であると同時に、停滞によって引き起こされる「症状」でもある。

📌 ダチ公主義を切り崩すためのヒント

  • 忖度させないルール作り： 自分の意見に対して「強引に改善点を3つ挙げさせる」など、あえて空気を読まない（是々非々）を強制する仕組みを組織に組み込む。
  • 「気まずいことを言う時間」の確保： 組織の中で、あえて摩擦を恐れずに本音をぶつけ合う時間を意図的に設ける。
  • 世代交代の受容： 上の世代が下の世代に「ビシバシ言う」必要はない。若い世代は独自のコミュニティで価値を届けており、それを尊重することも一つの解。
次回（最終回）の展望： 「所属しない自由」や「コウモリとして生きることの可能性」、そして「ダチ公をどう切るか」というテーマで、ダチ公主義の切り崩し方をさらに深掘りする。
