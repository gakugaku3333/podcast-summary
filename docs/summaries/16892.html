【西田幾多郎10】「無の哲学」と「絶対無の場所」：西洋哲学の極致から東洋の叡智へ

西田幾多郎シリーズ第10回。前回議論した「場所」の概念をさらに深掘りし、西田哲学の代名詞とも言える「無（絶対無）」の概念へと到達します。西洋哲学の論理を用いながら、東洋文化の根底にある直感に哲学的根拠を与えようとした西田の独創性が語られます。

📌 「場所」の再定義：主語から述語へ

  • 「我（私）」の捉え方の転換：西田は「我とは主語的統一ではなく、述語的統一でなければならない」と主張。
  • 物ではなく場所：私という存在は、独立した「物」ではなく、あらゆる現象が起こる「場所」である。
  • 抽象化の果て：個別の場所（真川さんの場所、山本さんの場所）を突き詰めて抽象化していくと、最終的にすべてを包み込む一つの場所にたどり着く。

📌 キーワード「絶対無（Absolute Nothingness）」

  • 「無」とは何か：単なる「欠如」や「何もないこと」ではない。「ある」も「ない」もすべてひっくるめて成立させる根源的なラベル。
  • ポップカルチャーでの例え：スター・ウォーズの「フォース」や、元気玉の「元気」のような、万物の根源的なエネルギーに近いイメージ。
  • 英語圏での評価：スタンフォード哲学百科事典などでは「Absolute Nothingness」と訳され、世界的に認められた独自の哲学的概念となっている。
  • 京都学派のシンボル：この「無」の概念が、後の京都学派の思想的な核となった。

📌 西洋哲学との対比：世界観の逆転

比較項目 西洋近代哲学（デカルト等） 西田幾多郎（場所の論理）
出発点 絶対的な観察者としての「我」 すべてを包み込む「場所」
主客の関係 主観（私）が客観（物）を分析する 主客は未分であり、場所において繋がる
実在の捉え方 個別の「物」が実在する 根源的な「無」が私として現れている
思考の方向 「我」を起点に外側を合理化する 「底」へ「底」へと潜り、根源に触れる

📌 東洋の叡智への哲学的根拠

  • 形なきものの形を見る：東洋文化（日本文化）の根底にある「余白」「わびさび」「声なき声を聞く」といった感覚。
  • 西田の野心：これらの東洋的な直感に対し、西洋哲学の文脈（ロジック）を用いて「哲学的根拠」を与えようとした。
  • 借用からの脱却：
    • 「純粋経験」はウィリアム・ジェームズから。
    • 「自覚」はフィヒテから。
    • しかし「場所」の論理に至り、西田はついに独自の哲学体系を確立した。
  • 老荘思想との共鳴：絶対無の概念は、道教の「無極にして太極」といった思想とも深く繋がっている。

📌 宗教的境地への入り口

  • 哲学と宗教の境界：西田は哲学と宗教を区別するが、哲学を極限まで突き詰めると「絶対無」に行き当たる。
  • 宗教的会心：絶対無の場所において、人間は真に自分自身と向き合い、自己を超えたもの（神や絶対者）とリンクする「会心」を経験する。
  • 親鸞への接近：この境地は、浄土真宗の親鸞の教えなどとも響き合うものになっていく。
