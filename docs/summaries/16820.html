【66-2】ローマを君に託す！政局をぶった斬るカエサルの遺言状

紀元前44年3月15日のユリウス・カエサル暗殺直後、公開された遺言状がローマに激震を走らせる。最有力後継者と目されていた右腕アントニウスを差し置き、指名されたのは無名の少年オクタウィアヌスだった。二人の対立と、混迷する共和制末期の政局を整理する。

ユリウス・カエサル マルクス・アントニウス オクタウィアヌス（アウグストゥス） アグリッパ レピドゥス キケロ 第二次三頭政治 遺言状 元老院

📌 カエサルの遺言状と後継者問題

  • 暗殺後の遺言状公開：紀元前44年、カエサルの死後に遺言状が公開された。当時のローマでは早めに遺言状を書く文化が普及していた。
  • 実子の不在：カエサルには正式な男子がいなかった（クレオパトラとの子カエサリオンは認知しておらず、相続対象外）。
  • 予想外の指名：
    • 周囲が本命視していたのは、カエサルの右腕アントニウス。
    • しかし、遺言状で第一相続人に指名されたのは、名の息子（親戚）である18歳の少年オクタウィアヌスだった。

📌 マルクス・アントニウス：野心的な右腕

  • 人物像と背景：
    • 名門の遊び人：名門出身だが若い頃から放蕩に耽り、莫大な借金を抱えていた。
    • 外見：見事な髭、広い額、わし鼻を持ち、自らの先祖と称する「ヘラクレス」のような高貴な風貌。
    • 能力：勇敢な軍人であり、ギリシャ留学で学んだ演説（修辞学）にも長けていた。
  • カエサルとの関係：
    • ガリア遠征に従軍し、カエサルにその勇敢さを認められ徴用される。
    • 五民官としてカエサルのために拒否権を行使し、それが無視されたことがカエサルのルビコン渡河の口実となった。
    • カエサルがポンペウスを追ってギリシャへ向かう際、本拠地イタリアの統治を任されるほどの信頼を得ていた。
  • 動機：名門としての出世欲と、莫大な借金を返済するための経済的成功。

📌 オクタウィアヌス：無名の天才少年

  • 人物像：
    • 早熟な知性：12歳で祖母の葬儀にて立派な弔辞を述べ、カエサルにその才能を見出される。
    • 身体的弱点：体が弱く、特にお腹が弱かったため常に腹巻きをしていた。
    • 性格：極めて忍耐強く、思慮深い。
  • 盟友アグリッパ：留学先のアポロニアで出会った生涯の友。戦争の天才であり、軍事能力の低いオクタウィアヌスを生涯支え続ける。
  • カエサルの名の継承：
    • 指名直後、周囲の反対を押し切り「ガイウス・ユリウス・カエサル」の名を継承すると宣言。
    • 政治経験ゼロの18歳によるこの決断は、極めて無鉄砲かつ大胆な賭けであった。

📌 激化する政治闘争

  • アントニウスによる妨害：
    • カエサルの妻カルプルニアからカエサルの公文書や財産を預かり、政治的主導権を握る。
    • オクタウィアヌスの相続手続き（民会での立法）を地味に邪魔し、権力移行を遅らせる。
    • 「オクタウィアヌスの祖先は奴隷だ」といったネガティブ・キャンペーンを展開。
  • オクタウィアヌスの逆襲：
    • 相続が滞る中、自らの資産を売り払ってまで、カエサルが兵士に約束していたボーナスを自腹で支払う。
    • これにより元カエサル軍の兵士たちの信頼を勝ち取り、独自の士兵（私兵）を集めることに成功。
    • アントニウスの提示額の5〜10倍の給料を提示して兵を引き抜くなど、札束による攻勢をかける。

📌 第二次三頭政治への道

  • 元老院の機能不全：
    • カエサルが元老院の定員を600人から900人に増やし、自身の息のかかった者を送り込んだため、組織としての能力が低下。
    • 共和制の旧システムでは、もはや広大な帝国と複雑な政局を裁ききれなくなっていた。
  • キケロの思惑：元老院の重鎮キケロは、アントニウスを抑えるために「オクタウィアヌスの方がまだマシ（操りやすい）」と判断し、彼を支援。
  • 異例の出世：
    • 元老院はオクタウィアヌスに軍の命令権（プロプラエトル）を付与。
    • さらに、戦死した失政官のポストを埋める形で、弱冠19歳ほどで失政官（コンスル）に就任。軍事力で元老院を脅して勝ち取った地位でもあった。
  • 共通の敵：アントニウスとオクタウィアヌスは一度戦うが、互いに決定打を欠いたため和解。共通の敵である「カエサル暗殺派（反カエサル派）」を倒すため、レピドゥスを加えた第二次三頭政治を結成する。
