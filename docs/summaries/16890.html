#022 Pepperを手がけたプロが語る、フィジカルAI時代に求められる人材と学習とは

元ソフトバンクロボティクスでPepperの事業に深く携わった山本力弥さんをゲストに迎え、フィジカルAI（物理世界で動くAI）の最新動向と、日本が今後取るべき戦略、そして求められる人材像について深掘りするエピソードです。

山本力弥 RobotMateHub Pepper フィジカルAI ヒューマノイド 中国ロボット市場 データファクトリー FDE (Forward Deployment Engineer) ロボットカーニバル

📌 ゲスト：山本力弥氏の経歴と活動

  • キャリア背景：エンジニアではなくビジネス側（コンサルタント）出身。事業会社でロボットビジネスに約10年従事。
  • Pepperとの関わり：誰もが知る白い受付ロボット「Pepper」の事業に深く関わっていた。
  • RobotMateHubの設立：約9ヶ月前に立ち上げたコミュニティ。フィジカルAIを学びたいビジネスマン、エンジニア、デザイナーが集まる場を提供。
  • 活動目的：ハード・ソフト・安全性・ビジネスなど多岐にわたるスキルが必要なフィジカルAI領域において、体系的な学びと交流の場を作る。

📌 世界の最新動向：中国と東南アジア

  • 中国（北京）の現状：
    • ハードウェアのコモディティ化が急速に進行。
    • 100〜200社が参加するカンファレンスでは、2足歩行・4足歩行・車輪型・配膳ロボットの「4点セット」をどの会社も自社プロダクトとして展示している。
    • 焦点はハードから「質の高い現場データの収集」と「再現性の高いデプロイメント」へシフトしている。
  • 東南アジア（タイ・ベトナム）の可能性：
    • データファクトリーとしての位置づけ。日本の製造業が多く進出しており、最先端のオートメーションと現場データが存在する。
    • 米中デカップリングの影響を受けにくいフラットな立場として、世界にデータを輸出する拠点になり得る。

📌 日本の課題とフィジカルAIの社会実装

  • ROI（投資対効果）の壁：
    • 中小企業の現場は属人性が高く、現在のロボット性能ではそのまま代替するのが難しい。
    • 大手（Amazon等）は専用ロボットアームで最適化されており、ヒューマノイドである必要性が低い。
    • 現状、日本では「実作業の代替」よりも「社内エンジニアの育成・教育」としての導入ニーズが先行している。
  • 現場主義の重要性：
    • ソフトウェアエンジニアもリモートワークだけでなく、「泥臭い現場」（配線や工場のライン）に足を運ぶべき。
    • 製造業のデータはセキュアな環境に閉じているため、自ら取りに行く姿勢が不可欠。

📌 求められる人材像：ジェネラリストとFDE

フィジカルAI時代には、従来の「ハード」「ソフト」という区分けではない新しい職能が求められています。

職種・概念 特徴と役割
ジェネラリスト 黎明期において、ハード・ソフト・安全・ビジネスを一気通貫で理解し、プロジェクトを牽引する人材。
FDE Forward Deployment Engineer。現場に入り込み、顧客と対話しながらクイックにAI実装や業務改善を行うエンジニア。
適合のプロ 海外製の優れたハードを、日本の複雑な現場インフラに適合（フィッティング）させる能力。日本人の得意領域。

📌 エンタメ領域での展開：ロボットカーニバル

  • プロジェクト概要：インフルエンサーのクリえみ氏らと共に、生成AIを活用したロボットアニメーションのコンテストを開催。
  • コンセプト：大友克洋氏の「ロボットカーニバル」をオマージュ。
  • 目的：日本ならではの「人とロボットの関係性」を文化的な側面から発信し、新しいロボットの姿を模索する。
  • スケジュール：直近でキックオフイベントを実施し、秋口に発表会を予定。
「フィジカルAIの勝負は、現場のデータをいかに効率的に取り、再現性高くロボットにデプロイできるかのサイクルにある。日本は現場を知るエンジニアを育成することが急務だ。」
