📌 GPT-6 Astra：3D生成とAGIへの接近

  • リリースの概要：一部ユーザーに先行展開中。数日以内にPlus、Pro、Business、Enterpriseユーザーへ提供予定。
  • 3D生成能力の飛躍：
    • 複数枚の写真から高精度な3Dモデル（Blender対応）を生成可能。
    • シムシティやフォールガイズのような有名ゲームのクローンを生成できるレベルのクオリティ。
  • AGI（汎用人工知能）説：ベンチマークや実用感から「これまでで最もAGIに近い」との評価が相次いでいる。
  • ネーミングの変遷：
    • OpenAIは宇宙系のコードネームを採用。SOL（太陽）、Terra（大地）、Luna（月）に続き、Astra（星々）が登場。

📌 Fable 5.1 と「Vibe Coding」の加速

  • Fable 5.1の進化：
    • 大量のタスク（10件程度の機能改善など）を一度に依頼しても、自律的に完遂する能力が向上。
    • 一発で直らなそうなバグの修正精度が上がっている。
  • 開発スタイルの変化：
    • Vibe Coding：厳密な設計より、AIとの対話でアプリを組み上げる手法が一般化。
    • TikTok等で、AI生成動画やAI生成音楽（Suno等）を組み合わせた個人開発アプリの広告が増加。
  • サブスクリプションの整理：
    • Cursor UltraからProへのダウングレードなど、各社モデルの性能均衡により「無駄な課金」を見直すフェーズへ。

📌 Gemini 3.8：高速性能と「熊・鮭」への寄り添い

  • モデル構成：3.8 Flashが主力。高速かつ安価で、日本語性能も非常に高い。
  • 課題：検索機能の不安定さ：
    • 「検索して教えて」と指示しても、既存知識で回答（ハルシネーション）してしまう傾向がある。
    • Google検索の「AIサマリー」は非常に高精度だが、Geminiアプリ版への統合が不十分。
  • 多様性への対応（？）：
    • 「私は熊です」「私は鮭です」といったロールプレイに対し、冬眠の準備や産卵ルートの案内など、異常に親切で詳細な回答を行う（通称：熊ファースト）。
