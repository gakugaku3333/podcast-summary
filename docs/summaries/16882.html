【黒川公晴】人間関係から対立をなくす法『NVC』ローゼンバーグ

元外交官であり、現在はファシリテーターとして活躍する黒川公晴氏をゲストに迎え、対人関係や組織開発の根幹となる「NVC（非暴力コミュニケーション）」の本質を探るエピソードです。外交の現場での経験と、人間理解の深い洞察が交差する内容となっています。

NVC（非暴力コミュニケーション） マーシャル・ローゼンバーグ 黒川公晴 外交官 ファシリテーション 組織開発 自己理解 共感 ニーズ

📌 ゲスト：黒川公晴氏のキャリアと哲学

  • 異色の経歴： 外務省入省、ペンシルベニア大学で組織開発学修士、ワシントンD.C.やイスラエル駐在、首相通訳官を経て、現在はファシリテーター・コーチとして活動。
  • 外交とファシリテーションの共通点： 外交官の仕事は「国内の利害調整」と「他国政府との交渉」であり、相手が何を大事にし、何を得たいかを理解してウィンウィンの着地点を見つけるプロセスそのものがファシリテーションである。
  • 交渉の本質： 権力で相手をねじ伏せるのではなく、お互いの事情を率直に共有し合いながら、落とし所を見つけていく対話のプロセスを重視する。
  • 起業の実験： 幼馴染ら6人と平等な議決権を持つ会社を設立し、福岡県糸島市で「プレイフル（楽しむこと）」をモットーとした実験的な組織運営を行っている。

📌 NVC（非暴力コミュニケーション）とは

  • 著者： マーシャル・ローゼンバーグ（紛争解決の専門家、メディエーター）。
  • 背景： 著者のユダヤ系としての被差別体験やデトロイトの暴動経験から、「なぜ人間は暴力に走るのか」「困難な状況でも非暴力でいられる人の違いは何か」を追求して生まれた。
  • 核心的な概念： 「暴力の本質は言葉にある」。人を値踏み、評価、比較、強要する言葉の使い方が暴力的な態度を醸成する。
  • 目的： 単なる対人スキルではなく、自分の内面を深く理解し、豊かな思いやりを持って他者とつながるためのフレームワーク。

📌 NVCを実践する「4つのステップ」

暴力性を解除し、誠実な対話を実現するための具体的なプロセスです。

ステップ 内容 ポイント
1. 観察 (Observation) 評価を交えずに事実だけを捉える 「全然聞いてくれない」は評価。「あの時、私が話した直後に自分の話を始めた」が事実。
2. 感情 (Feeling) その時に湧き上がった純粋な情動を特定する 「無視されたと感じた」は相手への評価。「寂しい」「不安だ」が自分の感情。
3. ニーズ (Need) 感情の根っこにある大事にしたい価値観を特定する 感情の原因は他人ではなく、自分のニーズが満たされているかどうかにある。
4. 要求 (Request) ニーズを満たすための具体的な行動を依頼する 「強要」ではなく「リクエスト」。相手がNOと言える余地を残すことが不可欠。

📌 NVCの深い洞察：感情の責任は自分にある

  • 感情の発生源： 「相手に言われたから腹が立った」と考えがちだが、実際には「自分の中に〇〇というニーズがあるから、その言動をきっかけに腹が立った」と捉える。
  • ニーズの普遍性： 「つながりたい」「貢献したい」「誠実でありたい」といった抽象度の高いニーズは、立場が違う人同士でも共通点を見出しやすく、対立の解消に役立つ。
  • リクエストと強要の見分け方： 相手が「NO」と言った時の自分の反応で決まる。冷たくなったり、罰を与えようとするのは「強要」。相手のNOの背後にあるニーズを理解しようとするのが「リクエスト」。

📌 視覚化：NVCによるコミュニケーションの変容

📌 「本当の自分」というラベルを剥がす

  • 自己の多面性： 「自分はこういう人間だ」とラベルを貼ると、それ以外の自分を許せなくなり、苦しくなる。
  • ポリフォニー（多声性）： 自分の中に矛盾する複数の側面（短気な自分、優しい自分など）があることを認める。
  • 寛容さの源泉： 自分の多面性に気づくことで、相手の多様な側面に対しても寛容になれる。
  • 結論： 「本当の自分」などという固定的なものはなく、環境や文脈によって引き出されるあらゆる側面が自分であると受け入れることが、生きやすさにつながる。
「暴力とは言葉である。言葉をどう扱うかで、人間の暴力的な態度は解除できる。」
