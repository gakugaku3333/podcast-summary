深津貴之のGUILD TALK：北欧、暮らしの道具店のAIネイティブな組織作り

株式会社クラシコム代表の青木耕平氏をゲストに迎え、創業20周年を控えた同社の組織運営、AI導入の現状、そして「ジャパンディ」をキーワードにしたグローバル戦略について、深津貴之氏が深く切り込みます。

📌 組織の「OS」の変遷とAIへの適応

青木氏は、会社の状態を把握するための「OS」が、物理的な環境からデジタルな履歴へと変化してきたと語ります。この変遷が、現在のAI活用における強力なアドバンテージとなっています。

フェーズ 観察対象 特徴
リアル時代 物理的な人の様子 「どんよりしている」「元気がある」など、空気感で組織を把握。
リモート時代 Slack等のログ コミュニケーションの履歴が可視化され、テキストで会社を見る。
AI共生時代 GitHub/MDファイル 意思決定の履歴やプロジェクトの更新履歴（コンテキスト）で会社を見る。
  • リモートワークへの最適化がAI時代の鍵：人と集まらないと仕事ができない組織は、AIとの協業においても不利になる。リモート下で資料共有やログ作成を徹底していた組織ほど、AIへの移行がスムーズ。
  • リアル会議でもログを残す：対面であってもZoomやMeetを立ち上げ、発話者ベースの履歴を残す習慣が重要。

📌 クラシコムの強み：仕組み化とクリエイティブの役割分担

ブランドや世界観が注目されがちな「北欧、暮らしの道具店」ですが、その裏側には徹底したオペレーションマネジメントが存在します。

クリエイティブを効率的に拡張する「二輪」の体制

  • 生産性の向上：直近3年間、人員をほぼ増やさずに売上を年率約20%成長させている。
  • コア機能の内製化：商品開発、デザイン、テック、倉庫マネジメントなど、企画の根幹（ストックされる部分）は社内に持ち、変動的な部分は外部パートナーと「ワンチーム」で運営。
  • 自社開発の基幹システム：ECを中心とした独自の基幹システムを構築。現在はWMS（倉庫管理システム）の開発も進めており、D2C専用の効率的なシステムとして外販の可能性も視野に入れている。

📌 グローバル戦略と「ジャパンディ」の可能性

日本独自の文化をそのまま輸出するのではなく、外来文化を日本で「謎進化」させて戻す手法に勝機を見出しています。

  • ジャパンディ (Japandi)：スカンジナビア（北欧）とジャパンを掛け合わせたスタイル。ヨーロッパ等で既にジャンルとして確立されている。
  • 「謎進化」のリミックス文化：
    • 中国のラーメン、インドのココイチのように、源流があるものを日本流にアレンジして返す方が受け入れられやすい。
    • 「北欧、暮らしの道具店」も、北欧文化を日本で独自解釈・進化させたものであり、それを海外に戻すアプローチは有効。
  • コンテンツ先行の検証：
    • AIを活用して多言語化したコンテンツをInstagramで配信。
    • 台湾（15万フォロワー）、US、韓国などで急速にファンを獲得。
    • 各国で受けるコンテンツは共通しており、「東アジア文化圏」という大きな括りでワンナラティブな展開が可能。

📌 AIネイティブな組織運営の具体策

非エンジニアが業務アプリを自作するフェーズから、AIが自律的にタスクを消化するフェーズへの移行を議論しています。

  • 非エンジニアによる開発：Claude等の活用により、エンジニアリング背景のない社員がガードレール（セキュリティ等の制約）の中で業務アプリを量産している。
  • 「やりたいことリスト」の自動消化：
    • 人間が直接AIと対話して待機するのではなく、GitHubのIssue等に「やりたいこと」を100〜1000個溜めておく。
    • AIエージェントが24時間体制で上から順番にタスクを消化していく運用。
  • マネジメントプレイブックの活用：
    • 青木氏が作成した約10万字の文書。言葉の定義（「要求」と「要望」の違いなど）を厳密に規定。
    • これがAIにとっての「最高の手本」となり、SlackやGitHub上での曖昧なやり取りをAIが自動で修正・補完する基盤になる。
  • 個人のログ（日記）の重要性：
    • 過去のSNS投稿や日記を構造化してAIに読み込ませることで、その人の判断基準を再現する「デジタルツイン」的な活用が可能になる。
    • 「本を書くより日記を書け、本はAIが作る」という考え方。
青木氏の言葉：「できるようになるために頑張るのではなく、もうできるんだということを知る。マトリックスの『早く動こうとするな、早いと知れ』という認識の変化が起きている。」
