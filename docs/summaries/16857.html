超相対性理論 #268 リーダーシップは誰のもの？／ゲスト：黒川公晴さん（その1）

ミネルバ大学の日本展開を手掛ける黒川公晴氏をゲストに迎え、リーダーシップの本質を「影響力」と定義した上で、それが個人の所有物なのか、あるいは関係性の中に立ち現れる現象なのかを、外交官や通訳としての稀有な経験から深掘りします。

ミネルバ大学 アダプティブ・リーダーシップ 外交官 通訳 影響力 関係理論 組織開発 ラーナーズラーナー

📌 ミネルバ大学とリーダーシッププログラム

  • ミネルバ大学の独自性：物理的なキャンパスを持たず、世界中を移動しながらオンラインで学ぶスタイル。ハーバード大学より入学が難しいとされる。
  • 学習の科学：学習者のエンゲージメントを最大化するために、問いの順番やアクティビティの構成が分単位で緻密に設計されている。
  • ファカルティ（教員）の役割：
    • 荒木氏も教員として参加。自由なスタイルが許されず、徹底した仕組み化と準備が求められる。
    • 「仕組み」という台本がある中で、いかに教員の個性がにじみ出ていくかが重要。

📌 ゲスト：黒川公晴氏の特異なキャリア

  • 外交官としての12年間：外務省に入省し、ワシントンDCやイスラエル・パレスチナに赴任。霞ヶ関では外国政府との交渉を担当。
  • トップリーダーの通訳：安倍元総理や岸田外務大臣（当時）の通訳を務め、国家リーダーの影響力を間近で目撃してきた。
  • 異例の起業：10年前、幼稚園からの幼馴染を含む6人で「一斉に会社を辞めて」福岡で起業（ラーナーズラーナー）。
  • 現在の活動：企業の組織開発・人材開発に加え、公立小学校でのリーダーシップ教育など、大人から子供まで幅広く展開。

📌 リーダーシップの定義：「影響力」

  • 定義：自分以外の他者や世界に対して、意図して及ぼしていく前向きな影響力。
  • スキルセット：システム思考、EQ（対人知性）、課題分析法など、具体的な思考習慣として育成可能。
  • 問いの核心：リーダーシップは「肩書き」ではなく全員が発揮しうるものだが、それは「個人の所有物」なのか、それとも「周囲との関係性」で決まるものなのか？

📌 通訳という「憑依」体験とリーダーシップ

  • 通訳の流派：
    • 黒子型：言語を正確に変換することに徹する。
    • 再現型：話し手の感情や場の雰囲気をすべてまとって再現する。
  • 岸田外務大臣（当時）の抗議の事例：
    • 沖縄での米軍属による事件に対し、ケネディ大使を呼びつけて抗議した際、黒川氏は日本側の「怒り」や「深刻さ」をトーンや単語選択に込めて訳した。
    • 「言葉の変換」ではなく、その場で達成すべき「目的」から逆算した表現。
  • リーダーシップとの共通点：
    • 能動的でも受動的でもない、何かが自分を通過していく「中道体」的な感覚。
    • 個人の意志だけでなく、文脈や関係性の中で「立ち現れる現象」としての側面。

📌 リーダーシップ研究の変遷

リーダーシップの捉え方は、歴史的に以下のように変化してきたと整理されています。

時代・理論 リーダーシップの所在・定義
特性理論 生まれ持った特定の「資質」や「性格」にある。
行動理論 特定の「行動」をとることにある。
状況適応理論 置かれた「状況」にどう適合するかにある。
コンセプト理論 変革型、サーバント型など特定の「型」にある。
関係理論（最新） 人と人との「関係性」の中に立ち現れる現象である。
