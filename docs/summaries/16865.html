超相対性理論 #269 リーダーシップは誰のもの？（その2）

ゲストに黒川公晴さんを迎え、「リーダーシップは個人のスキルなのか、それとも関係性の中で立ち上がる現象なのか」という問いを深掘りします。システム思考、ハンナ・アレントの哲学、そして平家物語まで、多角的な視点からリーダーシップの本質に迫るエピソードです。

黒川公晴 システム思考 創発 ミネルバ大学 ハンナ・アレント 人間関係の網の目 知的謙虚さ 平家物語 敗者のリーダーシップ

📌 世界観の転換：機械論からシステム思考へ

リーダーシップをどう捉えるかは、その人が「世界をどう認識しているか」に依存するという議論がなされました。

視点 機械論的世界観（従来型） システム思考・創発的世界観
リーダーシップの所在 個人のもの（スキル・行為） 集団・関係性の中に立ち上がるもの
因果関係 一対一の予測可能な因果関係 相互作用による予測不能な結果
責任の所在 個人の能力や責任に帰結する 場全体のプロセスとして捉える
課題 過度なコントロールへの期待 責任放棄やニヒリズムへの懸念
  • リーダー育成の矛盾：企業の「リーダー研修」は、個人のスキルアップを期待するが、実際には「個人の功績」をぼやかしていくアプローチが必要になるというジレンマがある。
  • コントロールの幻想：成果を出すことを強く求められるほど、リーダーは「世界をコントロールできる」という過信に陥りやすい。

📌 ハンナ・アレントに学ぶ「行為」の不確実性

哲学者のハンナ・アレントの言葉を引き合いに、人間が社会に働きかけることの意味が語られました。

「人は自分の人生という物語の主人公ではあるが、著者ではない」
  • 人間関係の網の目：一人が何かアクション（行為）を起こすと、それは他者との関係性の網の目の中に落ちていき、自分の意図しない形で全体の形を変えてしまう。
  • 開始と結果の乖離：何かを始めた人は、自分が何を始めたのかを最後まで知る術がない。その人の評価は、後から他者によって語られることでしか定まらない。
  • 権力と暴力の違い：
    • 暴力：道具であり、一人で所有・行使できるもの。
    • 権力：人々が共に集まり、相互作用している間にのみ存在する。誰も所有できず、人が散れば消えてしまう。

📌 「良い意思決定」と「正しい意思決定」

不確実な世界でリーダーが持つべき態度として、ミネルバ大学の教えが紹介されました。

  • 正しい意思決定は存在しない：その瞬間に「正しい」と定義できる決定はない。後から振り返って「正しかった」と言えるだけである。
  • 良い意思決定を目指す：自分の認知の範囲内で、可能な限りの情報と声を拾い上げ、熟慮を重ねて決めること。
  • 知的謙虚さと確信のバランス：
    • 過信：自分の力を信じすぎ、世界を単純化しすぎる。
    • ニヒリズム：どうせ分からないと諦め、思考停止に陥る。
    • 中道：自分の影響力を信じつつも、それが本当に正しいのか常に疑い、反応を観察し続ける。

📌 平家物語：敗者のリーダーシップと語り手

リーダーシップは「勝者」や「当事者」だけのものではないという、日本的な視点からの考察です。

  • 語り手による成立：平家物語は、琵琶法師という「社会の周縁にいた人々」が、負けた側の物語を語り継ぐことで成立した。
  • 第三者の視点：リーダーシップは、当事者が消え去った後、第三者がどう語るかによって事後的に形作られる側面がある。
  • 滅びの美学：成功や勝利だけでなく、「滅びゆくプロセス」の中にどのようなリーダーシップがあったのかを問うことも、現代において重要な視点となり得る。

📌 結論としての「存在の影響力」

  • 何もしないことも影響である：人は存在するだけで世界に影響を与えてしまう。無気力でいることも一つの作用である。
  • 納得できるチョイス：どうせ影響を与えてしまうのなら、自分なりに納得できる意図を込めて働きかけた方が、人生の充足感につながる。
  • 今後の展望：この「全員が世界に作用する」という考え方を教育に落とし込む際の弊害や、そこから取りこぼされる人々への救済について、次回さらに議論を深める。
