【67-1】甘く見んなよ！モンゴル帝国襲来 〜海門わたる未曾有の国難〜

本エピソードは、過去に配信された「チンギスカン編」と「鎌倉武士編」が交差する待望の新シリーズ第1回です。モンゴル帝国が日本に襲来した「元寇」をテーマに、当時の日本がいかに混沌とした「万人の闘争状態」であったか、そして北条氏がいかにして権力を集中させていったかの背景を整理します。

📌 シリーズの位置づけと福岡の記憶

  • 二つのシリーズの続編
    • 2020年配信「チンギスカン編」：クビライ・カンの代になり、モンゴル帝国が日本へ。
    • 2022年配信「鎌倉武士編」：承久の乱を経て、日本国内の武士たちがどう動いたか。
    • 世界史的なモンゴルの流れと、日本史的な鎌倉武士の流れが「元寇」で結実する。
  • 福岡における元寇の存在感
    • 福岡高校の校歌には「弘安以来六百載（こうあんいらいろっぴゃくさい）」という歌詞がある。
    • 福岡市の詩歌にも「元寇」に関する記述があり、地元の人々には「自分たちが追い返した」という強い感覚が残っている。
    • 元寇防塁など、今も物理的な遺構が残っている。

📌 鎌倉幕府の「ぐちゃぐちゃ」な実態

  • 万人の闘争状態
    • 当時の武士は「チンピラ」に近い存在。隙あらば他人の土地を奪い、親族間でも殺し合う。
    • 「一所懸命」：一つの土地に命を懸けるほど、土地の所有権が生存に直結していた。
    • ルールが機能しておらず、実力がすべてを決定する過酷な社会。
  • 幕府の存在意義
    • 武士たちが幕府に求めるのは「土地の安堵（権利の保証）」と「紛争の裁定（裁判）」。
    • 御恩と奉公：土地を守ってもらう代わりに、命を懸けて戦う実利的な主従関係。
  • エピソード：繁華街での乱闘
    • 有力御家人の三浦氏と小山氏が、鎌倉の繁華街（キャバクラのような店）で鉢合わせ。
    • 酔った勢いで野良犬を射るゲームをしていたところ、矢が向かいの店に飛び込み、あわや大戦争という騒動に発展。
    • 国務大臣クラスの重鎮であっても、中身は野蛮な「万人の闘争状態」の住人であった。

📌 北条氏による権力構造の変遷

  • 得宗（とくそう）とは
    • 北条氏の嫡流（直系の子孫）の家督を指す言葉。
    • 初代：時政、2代：義時、3代：泰時……と続き、8代が北条時宗。
    • 北条家の中でも「本家」としての権威を確立しようと、分家や他の有力御家人と常に内紛を繰り返していた。
  • 執権と連署
    • 執権：将軍を補佐する最高責任者。
    • 連署（れんしょ）：副執権。執権をサポートし、書類に連名で署名する役職。
    • 若年の得宗が執権に就き、年配の親族が連署として支える体制でガバナンスを維持した。

📌 北条泰時と「御成敗式目」の誕生

  • カリスマなき後のルール作り
    • 3代執権・泰時の時代、頼朝や政子といった創業者世代が死去。
    • 「この人が言うなら従う」という俗人的な統治が限界に達した。
  • 御成敗式目（1232年）
    • 武士のための初めての成文法。
    • 目的は「公平な裁判」と「御家人の不満解消」。
    • 内容の3分の1が土地や裁判に関する規定。
    • 評定衆（ひょうじょうしゅう）：13人程度の有力御家人による合議制を公的機関として整備。

📌 北条時頼による中央集権化

  • 反対勢力の徹底排除
    • 5代執権・時頼は、19歳で就任。
    • 北条得宗家に反抗的な勢力（三浦氏、千葉氏、足立氏など）を、次々と武力で滅ぼしたり追放したりして権力を固めた。
    • 「裏切る気はない」と言って別れた直後に攻め滅ぼすような、苛烈な権力闘争を勝ち抜く。
  • タイミングの妙
    • 時頼が国内の権力を得宗家に集中させ、中央集権化に成功した直後にモンゴルが襲来する。
    • もし日本がバラバラのまま襲来を受けていたら、歴史は変わっていた可能性がある。
