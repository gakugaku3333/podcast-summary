📌 Google重要人物の離脱と「Discovery Loop」の誕生

  • ジェフ・ディーン（Jeff Dean）氏を含む、Googleの伝説的エンジニア4名が離脱。
    • ジェフ・ディーン氏はGoogleに27年間勤務し、Google検索、Gmail、Google Ads、Geminiなどの基幹システムを構築した人物。
    • 「ビルを建てた建築家」というより「大量のビルを効率的に建てる仕組みを作った人」と評される。
  • 新団体「Discovery Loop」を設立。
    • AIエージェントのループを高速で回し、科学技術の発展や研究の高速化を目指す。
    • 営利企業ではなく「団体」としてのスタート。Googleも投資する見込み。
  • デミス・ハサビス（Demis Hassabis）氏の役割変更。
    • Google DeepMindの代表を退任し、会長職へ。
    • 商業的なGeminiの開発から離れ、よりアカデミックな研究や創薬企業（Isomorphic Labs）に注力する意向。
  • 人材流出の影響： OpenAIのイリヤ・サツケヴァー氏やAnthropicのダリオ・アモデイ氏など、現在のAI界のリーダーの多くが元Googleチーム出身であることが改めて注目されている。

📌 Meta版コーディングツール「Muse Code」登場

  • Metaからターミナルで動作するコーディングエージェント「Muse Code」がリリース。
  • 特徴と導入：
    • ターミナルにコマンドを1行入力するだけでインストール可能。
    • Metaのアカウント（Facebook/Instagram）とクレジットカード登録による認証が必要。
  • 既存ツールとの比較：
    ツール名 提供元 特徴
    Muse Code Meta ターミナル完結型。後発だがMetaエコシステムとの親和性。
    Claude Code Anthropic 高い推論能力。エンジニアの間で評価が高い。
    Codex (Cursor等) OpenAI系 普及率が高く、デスクトップアプリとして使いやすい。
  • 結論： 一般ユーザーは無理に乗り換える必要はなく、まずは一つのツール（ChatGPT WorkやClaude Artifacts等）を使い込むことが重要。

📌 動画生成AIの進化：SeeDance 2.5 & MiniMax H3

  • SeeDance 2.5：
    • 再現性の向上： 人物の顔の一致性が非常に高く、実写に近いクオリティ。
    • 利用方法： CapCut（ByteDance提供）に課金しているユーザーは、アプリ内クレジットを消費して手軽に利用可能。
  • MiniMax H3：
    • ローカル動作： 高スペックPCやGoogle Colab（月額5,000円程度のProプラン推奨）で動作可能。
    • 制御性： カメラワークや演出の自由度が高い。
  • AI動画の現状： 「タコが深海でサングラスをかけて踊る」といった、一見本物に見えるが嘘である動画が拡散。情報の真偽を見極めるのが困難な時代に突入している。

📌 実践：ファインチューニングの民主化

  • Unslothという軽量・高速な学習フレームワークにより、個人レベルでもファインチューニングが容易に。
  • 早川ゴミ氏の体験：
    • GemmaやQwenなどのモデルを使用。
    • ゲーミングPC環境で、1回の学習が15分程度で完了。
    • 「特定の口調（ヨーダ等）」を学習させるなど、データの重み付けを調整することで挙動を変化させられる。
  • 学び： 仕組みを知っている（Unsloth等のツールの存在を知っている）だけで、技術的なブレイクスルーのハードルが劇的に下がる。

📌 教育とロボティクス：ミニ四駆は「義務教育」

  • ロボットの3要素： センサー（認知）、知能（制御）、駆動（動作）。
  • ミニ四駆の価値：
    • 肉抜き（軽量化）、モーター選定、ローラーによるコース追従などは、ロボット工学の基礎そのもの。
    • タミヤのロボットキットは安価（2,000円〜）で、夏の自由研究に最適。

ロボットの定義：ミニ四駆や電子工作はこのサイクルを学ぶ最短ルート
