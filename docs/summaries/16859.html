【66-10】五賢帝時代はじまる！転ばない皇帝をこしらえる為のエトセトラ

フラウィウス朝の終焉から、ローマ帝国最盛期とされる「五賢帝時代」の幕開けを解説するエピソード。短命に終わったティトゥス、恐怖政治へ走ったドミティアヌスを経て、養子継承という新システムを確立したネルウァ、そして最大版図を築いたトラヤヌスの治世までを網羅します。

ティトゥス ドミティアヌス ネルウァ トラヤヌス 五賢帝 フラウィウス朝 ダキア戦争 アリメンタ制 オプティムス・プリンケプス パクス・ロマーナ

📌 フラウィウス朝の終焉：ティトゥスとドミティアヌス

  • ティトゥス（在位：79年 - 81年）
    • 父ウェスパシアヌスの不評を覆すため、ブランディング戦略を重視。
    • 元老院議員を処刑しないことを宣言し、支持を獲得。
    • 災難の連続：ローマ大火災、ペストの流行、ベスビオ火山噴火（ポンペイ埋没）。
    • 在位わずか2年、42歳の若さで病死。
  • ドミティアヌス（在位：81年 - 96年）
    • ティトゥスの弟。30歳で即位。非常に優れた行政手腕を持つ。
    • マイクロマネジメント：不当な裁判の無効化、賄賂を受け取った陪審員の罷免、属州総督の厳格な規制。
    • 恐怖政治への転落：娯楽への巨額投資で国庫が逼迫。財源確保のため有力者を処刑し財産を没収するようになる。
    • 厳格なモラル管理：退廃的な男女関係や同性愛を厳罰化し、世間から憎悪される。
    • 暗殺への恐怖：背後からの刺客を察知するため、散歩コースの壁を鏡のような大理石張りにした。
    • 最期：96年、皇后や側近たちによって寝室で暗殺される。元老院からは記録抹消（ダムナティオ・メモリアエ）の扱いを受けるが、軍や民衆からは一定の人気があった。

📌 五賢帝の1人目：ネルウァの苦悩と英断

  • 即位の経緯：ドミティアヌス暗殺後、元老院に推されて即位。フラウィウス家ではない元老院貴族。
  • 融和政策：流刑者の呼び戻し、没収財産の返還、福祉プログラムの実施。
  • 軍との対立：ドミティアヌスを慕う近衛隊（親衛隊）が反乱。ネルウァは軟禁され、先帝暗殺の首謀者を処刑させられる屈辱を味わう。
  • 養子継承の導入：自身の血縁にこだわらず、軍の支持が厚いトラヤヌスを養子に指名。
    • 実力主義の選定に見えるが、実際はスペイン出身派閥による政治闘争の結果という説もある。
    • 在位わずか16ヶ月で死去。最大の功績は「トラヤヌスを後継に選んだこと」。

フラウィウス朝から五賢帝時代への遷移

📌 トラヤヌス：ローマ帝国最大版図の実現

  • 出自：スペイン（イタリカ）出身。イタリア半島外で生まれた初めての皇帝。
  • 称号：オプティムス・プリンケプス（最良の皇帝）。
  • 内政とインフラ整備
    施策 内容
    都市監督官 地方都市の財政や行政をサポートする専門ポストを設置。
    大規模建築 アッピア街道の改修、ドナウ川への巨大な橋、港、浴場、水道橋の建設。
    アリメンタ制 低利で土地所有者に資金を貸し、その利子を貧困層の子供の養育基金とする福祉制度。
  • 軍事的成功：ダキア戦争
    • 現在のルーマニア付近（ダキア）を征服。全軍の3分の1を動員する大遠征。
    • 敵王デケバルスを破り、莫大な財宝を獲得。これにより国家財政が劇的に潤う。
    • 勝利を祝う祭典は123日間続き、1万人の剣闘士、1万1000頭の動物が投入された。
  • 最大版図の実現：ダキア、アラビア、メソポタミア、アルメニアを併合。総面積500万平方キロメートル、人口6000万人に達する。
  • 最期：パルティア遠征中に反乱や補給難に直面。脳卒中を発症し、ローマへの帰還途中にキリキアで死去（63歳）。

📌 考察：五賢帝時代の「身体感覚」と「運」

  • バランス感覚の重要性：成功する皇帝（アウグストゥス、ウェスパシアヌス、トラヤヌス）は、元老院・民衆・軍という3つのステークホルダーを満足させる「身体感覚的なバランス」を持っていた。
  • 失敗からの学習：成功者は先代の失敗（カエサルの暗殺、ネロの暴走）を間近で見て学んでいたが、失敗する皇帝は「今」しか見ていない傾向がある。
  • 養子継承の真実：五賢帝が続いたのは、実力主義というよりも「たまたま4代連続で実の息子がいなかった」という偶然の要素が大きい。
    • 5代目のマルクス・アウレリウスに息子（コンモドゥス）がいたことで、このシステムは崩壊する。
  • パクス・ロマーナの実態：強固な平和というよりは、外的要因やマーケット（征服対象）があるうちは維持できる「波乗り」のような不安定な繁栄であった。
「皇帝に必要なバランス感覚は、頭でわかっていてもできるものではない。こけて怪我をしながら覚えるスケボーのようなものだが、皇帝は一度こけたら死ぬ。だからこそ、即位前にどれだけ学んでいたかが生死を分ける。」
