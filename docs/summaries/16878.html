子育てのラジオ「Teacher Teacher」：13歳からの進路相談（with ユイロ）

福岡・天神の蔦屋書店で開催されたイベントの振り返りと、通信制高校サポート校「ユイロ」のマスさんを交えた進路相談の回答編です。ショート動画に慣れた子供の忍耐力、不登校児のオンライン進学、中学受験とお金の問題など、現代の親子が直面する具体的な悩みに、教育者と親の両面からアプローチしています。

ユイロ 通信制高校 不登校 中学受験 ショート動画 プロセスドリブン オンライン教育 自己決定 テキストコミュニケーション

📌 イベントの振り返りと運営体制

  • 天神蔦屋書店でのイベント成功： オフ会のようなリラックスした雰囲気で実施。参加者の満足度はほぼ100%という結果に。
  • チーム運営の進化： 以前は登壇者が設営まで行い余裕がなかったが、クミさん（運営）や小野春ちゃん（キッズスペース担当）の協力により、登壇者がトークに集中できる体制が整った。
  • スポンサーへの感謝： NEXT LINK、夢中教室、アイズ訪問看護、ステコボコ研究室などの支援により開催。
  • マスさんの著書： 「転校の教科書」を出版。出版イベントとしての側面もあり、出版社が会場費を負担。

📌 悩み相談1：ショート動画と「プロセスの軽視」

相談： ショート動画ばかり見て、時間をかけるプロセスを楽しめない・忍耐できない子供にどう接すべきか？

  • プロセスドリブンな声掛け： 成功した瞬間（結果）だけを褒めると「結果が全て」と学習してしまう。「あの時転んでも練習したから今があるんだね」と、成功時に過去のプロセスを接続するフィードバックが重要。
  • 親の価値観を伝え続ける： マスさんは子供に「ショート動画は脳の麻薬だ」と言い続けている。すぐには伝わらなくても、親が何を大事にしているかは子供の中に蓄積され、別の場面（ゲームのやりすぎ等）で自浄作用として現れることがある。
  • 「敵」にならない工夫： 否定から入ると子供は心を閉ざす。「何が面白いの？」と一緒に楽しむ目線に立ち、仲間になってから別の提案（一緒におやつを作る等）をする。
  • 逆転の発想： ショート動画を見ることを「1日30本見る」のようにタスク化・義務化すると、逆に嫌いになるという心理的メカニズム（劇薬だが一つの視点）。または、動画視聴を「アウトプット（自分で撮ってみる）」に繋げ、制作プロセスを体験させる。

📌 悩み相談2：中2不登校児のオンライン進学

相談： 身体症状（腹痛）で不登校の中2。オンライン授業を受けており、高校もオンライン通信制を希望している。親としてどう動くべきか？

  • 現状を肯定する： オンラインで学べていること自体が素晴らしい。「自分は学べる」という安心感が、次のステップへの勇気になる。
  • 「外に出る」の定義を広げる： 学校＝外に出る場所と限定せず、好きなアニメのイベントやアルバイトなど、「興味があること」をフックに外の世界と繋がる選択肢を提示する。
  • オンラインスキルの価値： 2020年以降、社会でもフルリモート・チャット中心の働き方が一般化した。テキストコミュニケーション能力を磨くことは、将来の強力な武器になる。
  • 自己決定の尊重： 中2で自ら進路を考えているのは非常に自立している証拠。親の尺度（全日制が普通）を捨て、本人が「今の自分でOK」と思える環境作りを優先する。

📌 悩み相談3：中学受験と家計の葛藤

相談： 小6不登校児が私立中受験を希望。家計はギリギリで、入学しても通えなくなるリスク（入学金が無駄になる不安）があり、背中を押せない。

  • 金銭状況を正直に伝える： 子供を見くびらず、家計の現状と親の不安をぶつけてよい。後から「あんなに払ったのに」と感情的に言うより、事前に共有することで子供も一人の人間として葛藤し、成長する機会になる。
  • 「何にお金を払うか」の再定義： 入学金は「卒業するための費用」ではなく、「子供が自ら決めてチャレンジする機会」への投資と捉える。たとえ途中で通えなくなっても、その意思決定の経験自体に価値がある。
  • 環境リセットの希望： 不登校の子供にとって、中学受験は人間関係をリセットし、新しい自分を始めるための切実な手段である場合が多い。
  • 親の「応援したい気持ち」をセットで： 「お金が大変だ」という事実だけでなく、「あなたの挑戦を応援したい」というポジティブな面も同時に伝える。

📌 結論としてのメッセージ

  • 「点」ではなく「線」で付き合う： 親子の関係も、Teacher Teacherとリスナーの関係も、その場限りではなく長い時間軸で捉える。
  • 執着を手放す： 親の期待や社会の標準という尺度を手放し、子供を一人の別の人間として尊重し、その子の納得感を重視する。
  • クイックな行動： 「やりたい」と言ったら、まずは話を聞きに行く、アルバイトをしてみるなど、今できる小さなアクションから始めてみる。
