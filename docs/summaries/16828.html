ロシア・ウクライナ両国の攻撃激化による小麦価格高騰と物流網の混乱

ロシアとウクライナが互いの穀物インフラや貨物船への攻撃を強めており、世界の小麦供給網が深刻な打撃を受けています。この軍事的な緊張に加え、気候変動や金融政策の影響が重なり、小麦の先物価格が約2年ぶりの高値を記録するなど、食料安全保障への懸念が急速に高まっています。

📌 穀物インフラおよび貨物船への攻撃状況

  • ウクライナ側の被害: ミサイルやドローン攻撃により、黒海経由の穀物輸出能力が3分の1減少。
    • 直近1ヶ月でオデッサ港周辺の船舶28隻が損傷。
    • 死者21人、負傷者34人の人的被害が発生。
    • ギニアビサウ船籍の貨物船が攻撃を受け、10人が死亡。
  • ロシア側の被害: ウクライナによるドローン攻撃の報復を受け、ロシアの穀物輸出の約25%を担うアゾフ海の船舶やターミナルが標的に。
  • 物流の停滞: ロシアは代替ルート（北極海・バルト海）を模索しているが、コスト面で現実的ではない。

📌 小麦市場の動向と価格高騰の要因

  • 価格の急騰: シカゴ小麦先物価格が1ブッシェル7ドルに到達。2024年5月以来の高値を記録。
  • 複合的な要因:
    • 軍事衝突: 世界の小麦輸出の28%を占めるロシア・ウクライナ両国の供給不安。
    • 天候不順: アメリカ国内における干ばつの懸念。
    • コスト増: 中東情勢の変動による肥料コストの上昇。

📌 金融政策と「1980年代農業危機」の再来懸念

  • 歴史的背景: 1980年代のアメリカでは、インフレ抑制のための急激な利上げ（政策金利20%近く）により、農家が利払い負担増と農地価格暴落で深刻な危機に陥った。
  • 現在のリスク: FOMCによる利上げ観測が強まっており、金利が上昇すれば、小麦価格が高騰していても農家が簡単に増産に踏み切れない構造（利払い負担増）が生じる。

📌 日本への影響と国内情勢

  • 輸入コストの増大: 小麦の多くを輸入に頼る日本にとって、国際価格の上昇は食料品の直接的な値上げ要因となる。
  • 物価動向: 消費者物価指数（総合）は前年同月比で1.7%上昇。
  • 国内米の状況: 昨年の不足から一転し、今年は価格の下落が指摘されるなど不安定な状況。
  • 今後の課題: 主食の値段は国民生活への影響が大きいため、政治による食料安全保障の徹底的な議論と説明が求められている。
「小麦価格が高騰しているからといって、農家が簡単に増産に踏み切れるわけではない。金利上昇や人手不足といった構造的な問題が、世界の食料供給を縛っている。」
