#023 | 30年赤字、3回会社売却。技術力で生き残るBoston Dynamics徹底解説

世界で最も有名なロボット企業の一つであるBoston Dynamics（ボストン・ダイナミクス）の歴史と、その特異な技術哲学、ビジネスの変遷を深掘りするエピソード。30年間の赤字を抱えながらも、なぜ彼らはトップを走り続けられるのか、その強さの源泉を解説します。

📌 ボストン・ダイナミクスの異常な技術哲学

  • あえて最も難しい課題から着手する：
    • 最初の開発は「4足」ではなく「1本足」のホッピングロボット。
    • 理由：1本足でバランスが取れれば、他の形状でも応用できるという「逃げ道をなくす」ドSな選択。
  • 「空中」でのバランス研究：
    • 地面に足がついていない状態（宙返りなど）での制御を追求。
    • アイススケーターのスピン（腕の位置で回転速度を変える）に着目し、重心制御を極めた。
  • 40年越しの技術回収：
    • 1980年代からの基礎研究が、2023年になってようやく「重い物を持ちながら不安定な場所でバランスを取る」という商用技術として結実した。

📌 30年の赤字と3度の買収劇

利益が出なくても技術力が評価され、親会社が変わりながら生き残ってきた稀有な歴史。

時期 親会社 目的と結果
2013年〜 Google ロボット事業の柱として買収。しかし事業計画に乗らず手放す。
2017年〜 SoftBank Pepperに続くロボット展開を狙うが、商売にするのが難しく売却。
2020年〜 Hyundai 自社工場の自動化・効率化を目的に80%の株を取得。現在、最も実用化が進んでいる。
  • Googleが「顧客」として再登場： かつての親会社Googleが、自社AI（Gemini等）の「体」としてAtlasを採用。手放した会社がお客さんになるという面白い逆転現象が起きている。

📌 探求と実用の使い分け（Spotの戦略）

技術を誇示するのではなく、現場での「確実性」を最優先する思想。

  • あえて視界を制限する：
    • 4足歩行ロボット「Spot」は、通常2メートル先までしか見えないように制限されている。
    • 遠くまで見せて推論させるとAIの不確実性が生まれるため、あえて近くのQRコードを読み取って自己位置を特定する「確実な方法」を採っている。
  • 「転び方」の設計：
    • 無理に踏ん張って複雑な動きで壊れるより、潔く「受け身」を取って故障を防ぐアルゴリズムを搭載。
  • ソフトウェアによる収益化：
    • Orbit: 複数台のロボットを一括管理するソフト。
    • Scout: 遠隔操作用ソフト。
    • 5年間のソフト利用料がロボット本体価格を超えるほど、ソフトでの投資回収モデルを構築している。

📌 過去の栄光を捨てる「油圧から電動へ」

  • 合理的判断： ボストン・ダイナミクスといえば「油圧」と言われるほどの蓄積があったが、現代のモーター技術の進化に合わせ、2024年に電動式へ完全移行。
  • 経営判断： 過去の成功体験に縛られず、その時々の最適解をパッと選択できる「職人魂と経営判断の両立」が彼らの強み。

📌 資金源と歴史的背景

  • 軍からの受注： 初期の資金源は軍（DARPAなど）からの依頼。山岳地帯で荷物を運ぶロボットなどの研究費で技術を磨いた。
  • シミュレーション技術： 最初期はロボット本体ではなく、シミュレーション用のソフトウェアを販売していた。
  • 長期スパンの強み： 通常のスタートアップは短期の資金調達に追われるが、彼らは大資本（Google, SoftBank, Hyundai）の下で「研究」として長期開発を続けられたことが、他社が追いつけない技術障壁を生んだ。
