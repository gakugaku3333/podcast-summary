【66-9】豊かさのウラには誰かいる！奴隷が支えるローマの便利な暮らし

帝政ローマ編の「おまけ回」として、当時の人々の日常生活を深掘りするエピソード。軍事的征服によって得た富がどのように社会に還元され、どのような格差やインフラ、文化を生んでいたのかを解説します。

インスライ（高層住宅） テルマエ（公衆浴場） パンとサーカス 奴隷制度 水道橋 検討士（グラディエーター） セステルティウス コレギウム（ギルド）

📌 社会構造と人口動態

  • 圧倒的な格差社会：
    • 総人口：約5,000万〜7,000万人（漢帝国と同規模）。
    • 富裕層：全体のわずか0.5%。
    • 非富裕層：99.5%。その大半は自給自足に近い農民。
  • 主要産業：農業（小麦、ブドウ、オリーブ）。現代のイタリア料理の基礎となる作物が当時から主流。
  • ローマ・パッケージ：ローマが征服した都市（パリ、ロンドン、スペイン等）には、水道橋、浴場、競技場といった「ローマ的インフラ」がセットで建設された。

📌 驚異のインフラ：上下水道と浴場

  • 上水道の技術：紀元前312年には既に存在。動力を使わず、絶妙な傾斜だけで遠方の水源から新鮮な水を運搬。
  • 水のクオリティへの執着：
    • 水源ごとに味を飲み分ける「利き水」のような文化があった。
    • 水道汚染には1万セステルティウスの超高額罰金。
    • 富裕層は自宅に噴水を引いており、パイプの太さに応じて水道料金を支払うシステム。
  • テルマエ（公衆浴場）：
    • 単なる風呂ではなく、運動場、プール、庭園、図書室、食事室を備えた「スーパー銭湯」以上の複合娯楽施設。
    • 衛生状態は必ずしも良くなく、油や垢、泥で水が濁っていたという記述もある。
  • 下水道：テベレ川に汚物を流していたが、規模は不十分。しかし、18世紀のロンドンやパリよりも1世紀のローマの方が公衆衛生インフラは進んでいたとされる。

📌 住宅事情：逆転の価値観「インスライ」

  • 高層集合住宅（インスライ）：人口100万人の過密都市ゆえに上に伸びた。現代のタワマンとは逆に、1階が最も高級。
  • 劣悪な上層階：エレベーターがないため水汲みが困難。火災や地震時の生存率が低いため、上に行くほど家賃が安い。
  • マナー問題：窓からゴミや糞尿を投げ捨てる者が絶えず、アウグストゥスは建物の高さを20m以下に制限する法律を作った。

📌 奴隷制度：社会を支える「話す道具」

  • 奴隷の定義：農場の道具は3種類あるとされた。
    • 口をきかないもの（農具）
    • 少し口をきくもの（家畜）
    • 非常に口をきくもの（奴隷）
  • 所有数によるステータス：
    階層所有奴隷数の目安
    一般市民2〜3人（家事労働から解放されるレベル）
    弁護士最低8人（これ以下だと信頼されない）
    元老院議員平均500人
    大富豪1,000人以上
    皇帝万人単位
  • 人権の欠如：奴隷は「動産」扱い。自由民が他人の奴隷を殺しても賠償金で済むが、奴隷が主人を殺せばその家の奴隷全員が処刑されるなどの過酷な連帯責任があった。

📌 食文化と宴席の狂気

  • 富裕層の珍味：クジャク、フラミンゴの舌、魚の内臓など、希少性を尊ぶグルメ文化。
  • 宴会のマナー：
    • 寝ながら食べる：クッションに肘をつき、横たわって食べるのが正装。
    • 吐いてまた食べる：満腹になってもさらに食べるため、鳥の羽を喉に突っ込んで意図的に吐き、食事を続けることが贅沢とされた。
    • ゲップとおなら：ゲップは礼儀。クラウディウス帝はおならを許可する法律を検討したという逸話も。
  • 一般市民の食：自宅に台所がないことが多く、外食（酒場やカフェ）が中心。サンドイッチのような軽食も存在した。

📌 パンとサーカス：民衆を操る娯楽

  • 娯楽の供給：皇帝の責務は「食料（パン）」と「娯楽（サーカス）」を与えること。
    • アウグストゥス時代：年間65日の祭日。
    • 2世紀後半：年間130日以上。2日に1回は何らかの見せ物がある状態。
  • 検討士（グラディエーター）：
    • 起源は貴族の葬儀での「血の供養」。
    • 敗者は観客の判断でその場で殺される殺人ショー。
    • 非常に人気があり、強い検討士は女性にモテるスター的存在でもあった。

📌 労働観と行政

  • 短時間労働：皇帝や官僚の公務は、平時は午前中で終了するのが一般的。午後は入浴や昼寝、社交に充てられた。
  • 権限委譲：都市の自治が機能していたため、中央政府のリソースは驚くほど少なくて済んだ。
  • 職業アイデンティティ：肉体労働は蔑まれたが、自分の職業に誇りを持つ職人は多く、墓石に仕事道具を彫り込む文化があった。
  • 平均寿命：乳幼児死亡率が極めて高く、平均寿命は20〜25歳程度。1歳までに3分の1が死亡する過酷な環境。
「ローマの繁栄は、圧倒的な数の奴隷と、徹底したインフラ整備、そして民衆の欲望をコントロールする『パンとサーカス』によって維持されていた。」
